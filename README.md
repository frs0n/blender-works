## AI 爆发 ｜ 终

随着 AI 的爆发，\
我再也没有动力继续创作这样的作品。

但每当重新翻看它们，\
我依然会想起当初为了一个画面，\
一点点调整构图、光影、材质与细节的那些时刻。

直到现在，我仍然清楚地记得，\
每一处细节为什么会被这样处理。

这些作品也许已经停在了过去，\
但那段创作的过程，我一直记得。
